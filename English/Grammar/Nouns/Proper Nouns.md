**A proper noun is a noun that is more specific than a common noun.**

Like that:
	John, Marie         (names)
	London, France   (places)
	Sony                    (names of companies)


## Special Rules for Proper Nouns:

### - Capital Letters with Proper Nouns:

We **`always`** use `C`apital `L`etter for the first letter of a name or proper noun

This includes names **of**:
	**people**
	**places**
	**companies**
	**days of the week**
	**months**

Examples:

```text
They like Antony. (not They like anthony)
I live in England
She works for Sony
The last day in January is a Monday
We saw Titanic in the Odeon Cinema
```

Sometimes, however for stylistic reasons, people may choose to ignore this rule to give their writing more a unique or "modern" look.

### Proper Nouns `without` THE

We **DO NOT** use "the" with
	names of people:	

| Category    | Example             |
| :---------- | :------------------ |
| first names | Bill (not the Bill) |
| surnames    | Clinton, Gates      |
| fullnames   | Hilary Gates        |

We **DO NOT** normally use "the" with
	names of companies:

```text
Renault, Ford, Sony, EnglishClub (not the EnglishClub)
General Motors, Air France, British Airways
Warner Brothers, Brown & Son Ltd
```

**If the full (registred) name of a company starts with "The", then we use "The" if we use the full name**

for example:

```text
The PostPublishing Public Co., Ltd
```

**In this case "The" is part of the company's name and must be capitalized like all names.**

We **DO NOT** normally use "the" for
	shops, banks, hotels etc named after a founder or other person (with -'s or -s)

| Category    | Example                          |
| :---------- | -------------------------------- |
| shops       | Harrods, Marks & Spencer, Macy's |
| banks       | Barclays Bank                    |
| hotels      | Steve's Hotel                    |
| restaurants | Joe's Cafe, Mc Donald's          |
| churches    | St John's Church                 |
| cathedrals  | St Peter's Cathedral             |

We **DO NOT** normally use "the" with
	names of places

| Category   | Example                                       |
| :--------- | --------------------------------------------- |
| towns      | Washington (not The Washington), Paris, Tokyo |
| states     | Texas, Kent                                   |
| regions    | Eastern Europe                                |
| countries  | England, Italy, Brazil                        |
| continents | Asia, Europe, North America                   |
| islands    | Corsica                                       |
| mountains  | Everest                                       |

**EXCEPTION** If a country name includes "States", "Kingdom", "Republic" etc., we use "the"

| Category | Example                                                 |
| :------- | ------------------------------------------------------- |
| states   | the United States, the US, The United States of America |
| kingdom  | the United Kingdom, the UK                              |
| republic | the French Republic                                     |

We **DO NOT** use "the" with
	President/Doctor/Mr etc + Name

| Category                   | Example                                             |
| :------------------------- | --------------------------------------------------- |
| the president, the king    | President Bush (not the President Bush)             |
| the capitan, the detective | Capitan Kirk, Detective Colombo                     |
| the doctor, the professor  | Doctor Well, Dr Well, Professor Dolitte             |
| the uncle, your aunt:      | Uncle Jack, Aunt Jill                               |
| the mister                 | Mr Gates (not the Mr Gates), Mr Clinton, Miss Black |

examples:

```text
I wanted to speak to the doctor
I wanted to speak to Doctor Brown
Who was the president before President Kennedy?
```

We **DO NOT** use "the" with
	"Lake/Mount + Name":

| Category  | Example       |
| :-------- | ------------- |
| the lake  | Lake Victoria |
| the mount | Mount Everest |

examples:

```text
We live beside Lake Victoria
We have a fantastic view across the lake
```

We **DO NOT** normally use "the" for 
	**roads**
	**streets**
	**squares**
	**and parks**

| Category | Example                                           |
| :------- | ------------------------------------------------- |
| streets  | Oxford Street, Trenholme Road, Fifth Avenue       |
| squares  | Trafalgar Square, Ounble Place, Piccadilly Circus |
| parks    | Central Park, Kew Gardens                         |

**Many important buildings have names made of two words (for ex: Kennedy Airport). If the first word is the name of a person or place, we do not normally use "the"**

| Category | Example                                                |
| :------- | ------------------------------------------------------ |
| people   | Kennedy Airport, Alexander Palace, St Paul's Cathedral |
| places   | Heathrow Airport, Waterloo Station, Edinburgh Castle  |

### - Proper Nouns with THE

We **NORMALLY** use "the" for country names that include:
	**States**
	**Kingdom**
	**Republic**
	and etc

| Category | Example                                |
| :------- | :------------------------------------- |
| States   | the United States of America / the USA |
| Kingdom  | the United Kingdom / the UK            |
| Republic | the French Republic                    |

We **NORMALLY** use "the" for names of:
	**canals**
	**rivers**
	**seas**
	**oceans**

| Category | Example                                  |
| :------- | ---------------------------------------- |
| canals   | the Suez Canal                           |
| rivers   | the River Nile, the Nile                 |
| seas     | the Mediterranean Sea, the Mediterranean |
| oceans   | the Pacific Ocean, the Pacific           |

We **NORMALLY** use "the" for **plural** names of people and places:

| Category                      | Example                               |
| :---------------------------- | ------------------------------------- |
| people (families for example) | the Clintons                          |
| countries                     | the Philippines, the United States    |
| island groups                 | the Virgin Islands, the British Isles |
| mountain groups               | the Himalayas, the Alps               |

Look at these sentences:

```text
I saw the Clintons today. It was Bill's birthday.
Trinidad is the largest island in the West Indies
Mount Everest is in the Himalayas
```

We **NORMALLY** use "the" with following sorts of names:

| Category            | Examples                                        |
| :------------------ | ----------------------------------------------- |
| hotels, restaurants | the Ritz Hotel, the Peking Restaurant           |
| banks               | the National Westminster Bank                   |
| cinemas, theaters   | the Royal Theatre, the ABC Cinema               |
| museums             | the British Museum, the National Gallery        |
| buildings           | the White House, the Crystal Palace             |
| newspapers          | the Daily Telegraph, the Sunday Post            |
| organizations       | the United Nations, the BBC, the European Union |

We **NORMALLY** use "the" for names made with **of**

```text
the Tower of London
the Gulf of Siam
the Tropic of Cancer
the London School of Economics
the Bank of France
the Statue of Liberty
```
